# 角线 · Angleline

《角线》是用 Godot 制作的 Windows 第一人称手感练习场，支持离线练习和双人局域网陪练。

## 运行

从 [GitHub Releases](https://github.com/dsk66625/angleline/releases/latest) 下载最新版 Windows x64 压缩包，解压后运行 `Angleline.exe`。从 v0.5.1 开始，游戏从公开的 GitHub 发行页检查并下载更新。「游戏更新」在 Esc 设置菜单内。

使用 Godot 4.6.1 打开仓库根目录的 `project.godot`，按 F6 可运行打开的场景，按 F5 可启动完整游戏。Windows 导出使用仓库内的「Windows Desktop」预设和对应版本的 Godot 导出模板。

操作、准星设置与手感校准记录见[试玩说明](./试玩说明.txt)。
