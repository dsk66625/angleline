《角线》v0.9.6 ｜ Windows 手感试玩

启动
双击 Angleline.exe。首次启动会显示设置。填入你平时的 CS2 鼠标灵敏度，选择画面比例，然后点击「进入练习」。
在默认鼠标轴设置下，保持同一只鼠标和 DPI，水平转身距离可以直接用同一个灵敏度数值对照。
如果在 CS2 自定义过横纵轴，请把 m_yaw ÷ 0.022 填入水平倍率，把（m_pitch ÷ 0.022）× sensitivity_y_scale 填入垂直倍率。
设置在点击「进入练习」时保存。按 Esc 随时返回设置。

武器与动作（v0.9.6）
主武器仿 AK-47（罩式准星、导气管、上下木护木、肋纹弯弹匣、机匣盖肋、拉机柄与选择杆），手枪仿 USP-S（开槽消音器、套筒防滑纹、抛壳口、握把贴片），近战为爪子刀（鹰嘴刃带磨刃线、柄部指槽、尾指环）。
双手为手指级手套模型：拇指与食指各有两个可动关节，其余三指独立建模，手腕带袖口与前臂衣袖。握姿按 CS2 摆放——步枪左手托护木、右手握握把且食指搭扳机，手枪双手叠握，爪子刀反握、食指穿指环。
切换武器有 0.22 秒抬枪部署（爪子刀翻转入握）；R 换弹由支援手完整演出：离握→按弹匣卡榫→掉匣→取新匣→插匣→拉机柄/套筒后拉→回握，手指随动作张合（手枪 1.55 秒、步枪 2.10 秒，与判定时长一致）。
F 检视：步枪侧翻看机匣、手枪转看消音器、爪子刀绕食指指环双翻（翻转身其余手指张开）；开火、切换或换弹会立即取消检视。
开火带视图模型后坐、食指扣扳机、枪机/套筒往复与星形枪口闪光（消音手枪闪光更小）；近战挥击为 0.26 秒弧线；移动有步幅摆动、转头有视角 sway、落地有下沉，全部纯表现，不影响散布与命中判定。
第三人称剪影使用同一套武器与手部模型。静止时手指合并为单一网格以节省绘制开销，动作播放时才启用独立关节。
v0.9.1 修复穿模：手部改按握把圆柱求解摆放——指节以弦线包绕握把外缘、掌心留出间隙，握把／护木／刀柄截面改为圆角方形与求解半径匹配；手指改为连续锥段、袖口收细；爪子刀刃面朝向镜头、钩刃完整可见。
v0.9.2 修复"看到武器内部"：挤出网格的端盖绕序修正、磨刃刃面补齐封盖，机匣／弹匣／刀刃均为封闭实体；按用户要求移除移动时武器晃动（跑动中视图模型保持稳定，保留转头 sway 与落地下沉）；视图模型加一盏只照近距的补光，金属与木件明暗更有体积感。
v0.9.3 按用户要求移除落地下沉；视图模型材质改双面渲染并闭合扳机护圈，任何角度都不会再露出空腔内部；爪子刀握持按 CS2 反握重解：柄轴斜向左下、指环在拳顶、钩刃宽面朝向镜头、前臂自右下进入。
v0.9.4 爪子刀握姿进一步对齐 CS2：掌侧／拇指侧朝镜头、指环套在食指根部并藏入拳内、柄只露出拳底一小段、钩刃以宽面自拳底勾向左下、前臂自右下进入；修复刃剖面自交导致封盖缺失（此前钩刃只剩一条线）。
v0.9.5 爪子刀稳态剪影再对齐参考：钩刃加长放平、自拳底向左勾出；柄轴后倾使指环落在食指顶而非腕侧；拳头拉近镜头。QA 增加持刀稳态帧（部署落定后／全部动作结束后）并打印刀节点旋转，确认 idle 无残留翻转。
v0.9.6 修复落地瞬间武器抖一下：腾空偏移原先是着地帧硬开关（单帧跳 2cm），改为指数平滑过渡；新增 vm_land.gd 回归测试，落地后逐帧最大位移 1.6mm（阈值 4mm）。

自定义准星
在设置中打开「准星设置」，可以选十字、T 形或圆点，预览颜色、粗细和描边。十字和 T 形还可以调整线长、单侧间距，或加上中心点。
要对齐本机 CS2 的静态十字，在 4:3、1280×960 下点「CS2 静态准星」。此预设的线长、粗细和单侧间距分别为 2、2、1 个渲染像素。黑边模式保留比例，拉伸模式下准星随画面一起拉伸。
开启动态散布后，线段会随游戏内散布向外张开。用「模拟移动」可以在预览区对比静止与移动时的准星。
点击「进入练习」应用并保存，下次启动会沿用。直接按 Esc 返回靶场会放弃本次编辑。要找回原版绿色十字，可在准星页恢复默认，再点击「进入练习」。

游戏内更新
游戏每次启动会从公开的 GitHub Releases 检查正式发行版并在后台下载新版。也可在设置中点「游戏更新」→「检查更新」。整个过程可直接使用，无需登录或令牌。
看到「重启并更新」就可以安装。更新包通过 SHA-256 校验后才会替换当前目录的 Angleline.exe。使用 v0.5.0 或更早版本的玩家，可以先从 GitHub Releases 下载一次 v0.5.1 或更新的试玩包。

在靶场里
WASD 移动，点按空格起跳，长按空格可在每次落地时自动连跳。滚轮向上、向下各触发一次跳跃，可在落地时拨动滚轮手动接跳。Shift 静步，Ctrl 蹲。
数字键 1 切主武器（步枪），2 切手枪，3 切近战刀。持枪时左键射击、R 换弹。持刀时靠近靶面或陪练，点左键挥刀，按住左键可连续挥动。F2 回到出生点并补满弹药。
左前方的 C/01 墙角用于试急停，前方有四个靶。右侧的跳台用于试连续起跳。可以观察左下角的游戏内速度、首发状态和散布角。
以步枪为例，平地满速 215 u/s。试着先满速横移，松开 D 直接开一发，再复位重复，改为松开 D 后轻点 A 再开火。
手枪和步枪在落地停稳后都没有随机散布，连续开火也会沿当时的瞄准方向发射。镜头仍会随开火产生后坐力。移动和腾空会产生散布。

KZ 身法练习
先按住 Ctrl 蹲稳再跳，可以保持低姿态起跳。先跳后按 Ctrl 会在空中收脚 9 u，适合跨上高箱边缘。角色站高 72 u，蹲高 54 u。低顶下松开 Ctrl，角色会在站立空间足够时起身。
助跑后长按空格，离地后松 W，交替按 A 并向左转、按 D 并向右转，用左下角的速度读数判断是否加速。连跳时保留累计水平速度；转弯角度、触墙和在地面多停一步都会影响下一跳的速度。
持械速度对照 CS2 的 AK-47、P250 和默认刀。以下均为平地稳态速度（u/s），依次列出直跑、Shift 静步、Ctrl 蹲行。
1  主武器（步枪）　215.0 / 111.8 / 73.1
2  手枪　　　　　　240.0 / 124.8 / 81.6
3  近战刀　　　　　250.0 / 130.0 / 85.0
空中加速系数为 12，沿输入方向的目标分量为 30 u/s，累计水平速度没有硬上限。
从平地起跳再落回同一高度：站跳的脚底最高升高 55.83 u，约 375 ms 到顶、750 ms 触地。先蹲稳、保持蹲姿起跳时升高 57.00 u，约 758 ms 触地。站跳后在到顶前收脚并保持到落地，可升高 64.83 u，约 781 ms 触地。

视角和帧率
在「世界视角」选 4:3 黑边或拉伸，再在「渲染分辨率」选 1280×960。黑边保持比例，拉伸铺满可用画面。
选「原生宽屏」和 2560×1440 可获得原生 16:9。可全屏或窗口运行。选定分辨率是游戏实际渲染尺寸，窗口会按桌面可用大小适配。
4:3 可选 1024×768、1280×960、1440×1080、1600×1200、1920×1440，水平世界视角为 90°。
16:9 可选 1280×720、1600×900、1920×1080、2560×1440，水平世界视角约为 106.26°。
可选择不限帧、240 FPS、360 FPS 或自定义上限。默认关闭垂直同步。游戏右上角显示最近一段时间的平均帧率和 P99 帧时间。

双人局域网陪练
房主在设置内点击「开房」。另一台电脑填房主的局域网 IP 和相同端口后点击「加入」。默认 UDP 端口是 27428。
联机两端请使用同一版本。同机启动两个实例时，加入地址填 127.0.0.1。连接后双方在同一靶场移动、开火。

本机手感校准
跳跃轨迹取自三份本机 CS2 Dust II 比赛录像（协议 14129、14141、14161）。35 次起跳前已连续接地至少一秒、全程未蹲且落回同一高度的跳跃，在 64 Hz 录像中采到的最高点中位数为 55.82 u。逐帧拟合得到重力约 800 u/s²，站姿有效起跳速度约 298.87 u/s，到达顶点约需 373.6 ms，回到起跳高度约需 747.2 ms。三次空中由站转蹲测得收脚约 9 u。另有一次全程蹲姿的同高跳跃，最高点为 56.97 u。
《角线》每个物理步为 7.8125 ms。上面的试玩触地时间取角色第一次被判定为着地的物理步。从高 64 u 的平台站跳到低处，试玩版实测为 921.875 ms。
以下地面移动、射击和视野对照取自同一台电脑上的 CS2 1.41.9.9 离线练习，使用平地站姿 AK-47。CS2 录像按 64 Hz 采速度，按键有步内时间。《角线》按 128 Hz 采样。
静止起步，CS2 七次录像达到 50%／90%／满速的首个样本中位数为 146.0／380.1／555.4 ms。《角线》为 140.6／375.0／562.5 ms。
满速松键，CS2 六次测试的停距中位数为 32.54 u，首个零速样本中位数 367.8 ms。《角线》滑停约 32.55 u、367.2 ms。
两次反向急停的方向键间隔为 8.06 与 8.54 ms，CS2 松键后向原方向多走 12.52 与 12.57 u。《角线》以 7.8125 ms 间隔回放时为 12.46 u。
在该反向回放中，《角线》松键后 78.1 ms 进入旧版的平地首发基准速度范围。CS2 第一组约 78 ms 的样本已经进入该速度范围。v0.5.0 的随机散布在落地停稳时归零，反向输入跨过零速的两个物理步之间可能没有静止采样。
CS2 六组单发逐步记录得出额外散布衰减 90% 需约 368 ms。《角线》移动或腾空时使用这条恢复曲线，逐步回放首次达到 90% 恢复的采样点为 375 ms。
本版以每步前后速度的平均值计算平地位移。反向过头时，步枪散布会随实际速度再次扩大。拟合移动散布的实测样本覆盖到 141 u/s。
世界视野用固定站位、已知 30° 转角和画面地标核对。原生 16:9、2560×1440 下，CS2 截图估计水平约 106.2°、垂直约 73.5°。《角线》相机实测水平 106.26°、垂直 73.74°，落在截图人工读数误差内。
